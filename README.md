# Portfolio / Dblmok

Статический сайт на Astro, TypeScript и Three.js. Английская версия находится в `/`, русская в `/ru/`, финская в `/fi/`.

## Запуск и остановка

Открой папку Portfolio в VS Code. В терминале PowerShell:

```powershell
npm.cmd ci
npm.cmd run dev -- --background
```

Первую команду выполняй только после скачивания проекта или изменения зависимостей.
Открой http://localhost:4321. Сервер работает в фоне даже после закрытия VS Code.

```powershell
npm.cmd run dev -- status
npm.cmd run dev -- stop
```

Используем npm.cmd, чтобы не менять политику PowerShell. Нужен Node.js 22.12 или новее, проверено на Node.js 24.

## Как работает сайт

1. Astro читает данные проектов из Markdown.
2. Общие шаблоны получают эти данные и текст выбранного языка.
3. При сборке Astro создаёт готовые HTML-страницы в dist.
4. Браузер загружает обычные страницы. Three.js и модель загружаются после нажатия кнопки 3D.

Здесь нет базы данных, сервера для запросов или отдельного приложения на React.

## Новый проект

Скопируй один из файлов в src/content/projects и измени данные. Имя файла задаёт адрес страницы, например cafe.md создаёт /projects/cafe/.
Обязательны number, title, category, image и alt. Списки overview, tools, gallery и technical можно оставить пустыми.

image ведёт на полный рендер. Необязательные preview и thumbnail ведут на меньшие картинки для страницы и карточек. Если их нет, используется image.
Для текущих пяти работ превью создаёт scripts/prepare-images.py, нужен Python с Pillow.

kind задаёт тип работы: 3d, game, video или design. В каталог Models попадают только 3d. featured управляет показом на главной. Сайт готов к добавлению игр, но их описания и материалы ещё не добавлены.
Для новой работы добавь переводы в src/i18n/project-translations.ts. Пока перевода нет, выводится английское описание.

## Просмотр 3D

model задаёт путь к GLB, topology к JSON с исходными рёбрами. lighting: night включает свет комнаты, studio используется по умолчанию.

GLB хранит треугольники для отображения поверхностей. Кнопка исходной сетки использует отдельные рёбра Blender до модификаторов, чтобы не показывать диагонали экспорта.

Three.js рисует кадр при движении камеры и изменении размера. Постоянного цикла анимации нет. Закрытие 3D освобождает память GPU.
При ошибке остаётся рендер и кнопка повторной загрузки. При изменении GLB меняется версия его ссылки, чтобы браузер не показывал старый файл из кеша.

Night Room экспортирован из утверждённого NightRoom_cleaned-review.blend. Фон, объёмный туман, Boolean-резаки и скрытая от камеры оболочка исключены. Материалы стен и ковра адаптированы для браузера. У ковра устранено мерцание с полом, улучшена точность глубины камеры. Blender-оригинал не изменён.

Освещение, туман и волосы ковра не воспроизводятся точно как в Blender. Эталон итогового вида находится на рендере над просмотрщиком.

У Cafe, Gunsmith’s room, Island и Night Room подключён просмотр 3D. У Forest пока рендер: в исходнике отсутствуют текстуры машин, а сцена с растительностью требует отдельной подготовки.

## Проверки

Останови dev-сервер перед этими командами, чтобы Vite не использовал одновременно старый и новый кеш зависимостей.

```powershell
npm.cmd run check
npm.cmd run build
npm.cmd run test:site
```

check проверяет TypeScript и Astro. build создаёт dist. test:site проверяет маршруты всех языков, ссылки, файлы изображений и отсутствие служебных боксов в Night Room.
Не редактируй dist вручную. Эта папка создаётся заново.

## GitHub Pages

Файл .github/workflows/deploy.yml подготовлен: установка зависимостей, проверка, сборка, проверка ссылок и публикация при push в main.
В GitHub нужно создать репозиторий сайта, загрузить исходники и выбрать Settings > Pages > Source > GitHub Actions.
Репозиторий: https://github.com/sg06022006-prog/Portfolio. Сайт: https://sg06022006-prog.github.io/Portfolio/. Публикация настроена через GitHub Actions.

В Actions адрес и подпапка вычисляются из GITHUB_REPOSITORY. Для репозитория username.github.io используется корень, для остальных /repository/.
Для своего домена можно задать SITE_URL и BASE_PATH в шаге сборки. BASE_PATH нужно также передать шагу test:site.

В Git отправляются исходники и public. node_modules, .astro, dist, review и model-preparation исключены из Git.
При ручной загрузке на статический сервер загружай содержимое dist. Папки src, scripts и node_modules на сервере не нужны.
Скрипты экспорта Blender нужны только при обновлении моделей. Они читают сцены с диска D и создают веб-копии в проекте, оригиналы не сохраняют.

## Личный проект Gunsmith’s room

Gunsmith’s room стоит вторым после Cafe. Поле status: in-progress показывает пометку «В работе».
Скрипт scripts/prepare-full-scene.py с аргументами -- --prepare создаёт GLB, исходные рёбра и обзорный рендер из FullScene — копия.blend. Камера и свет добавляются только в памяти, оригинал не перезаписывается.
Затем выполни compress-glb-textures.py для GLB и prepare-images.py для превью.

lighting: soft включает приглушённый студийный свет. viewDirection задаёт начальное направление камеры.


Экспозиция просмотрщика задаётся полем exposure в файле проекта: Cafe и Island 0.45, Night Room 0.4, остальные по умолчанию 1. Меньшее число уменьшает яркость итогового кадра. Процедурный цвет крыши Island (Random Per Island и ColorRamp) запекается в PNG в scripts/export-scenes.py перед экспортом, потому что glTF не хранит такие ноды Blender.

## Обновление моделей

Запускай Blender-скрипты из папки Portfolio. scripts/export-scenes.py принимает имя cafe, island, night-room или forest после -- и создаёт черновой GLB в model-preparation/drafts.
Проверь результат перед заменой соответствующего файла в public/models. scripts/export-source-edges.py обновляет исходную сетку Cafe, Island и Night Room.
scripts/compress-glb-textures.py принимает путь к GLB и сжимает его текстуры на месте, сохраняя геометрию. Нужен Python с Pillow.

Временные экспорты и отчёты создаются в model-preparation, проверочные снимки в review. Они не нужны для сборки и публикации.


Процент в просмотрщике показывает скачивание GLB. После скачивания появляется «Подготовка сцены», пока браузер декодирует текстуры. Размер берётся из файла при сборке, чтобы сжатие HTTP не искажало процент. Адрес Gunsmith’s room остаётся /projects/full-scene/, чтобы существующие ссылки продолжали работать.
